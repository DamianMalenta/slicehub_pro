# SliceHub SPARK — jak obejrzeć i pobrać paczkę

## Gdzie wejść (online, bez instalacji)

1. **GitHub — folder materiałów**  
   https://github.com/DamianMalenta/slicehub_pro/tree/main/_docs/SPARK_materialy

2. **Wideo finałowe (montaż 7 procesów)** — kliknij plik → **Download** / **Raw**:  
   https://github.com/DamianMalenta/slicehub_pro/blob/main/_docs/SPARK_materialy/wideo/spark_forno_procesy_final.mp4

3. **Jedna paczka ZIP (wszystko naraz)** — na dole folderu SPARK_materialy:  
   `SPARK_Forno_Pakiet.zip` → przycisk **Download**

4. **Podgląd w przeglądarce (po rozpakowaniu ZIP)**  
   Otwórz **`START.html`** (dwuklik) — strona z linkami do wideo, screenów i dokumentów.

## Co jest w paczce

| Folder / plik | Zawartość |
|---------------|-----------|
| `wideo/spark_forno_procesy_final.mp4` | **Główne demo** (~2 min) — 7 procesów biznesowych |
| `wideo/spark_P1_…` … `spark_P7_…` | Surowe nagrania P1–P7 (Online, KDS, Track, Courses, Driver, KSeF, BI) |
| `hero_01_hub.png` … `hero_10_kds.png` | Screenshoty modułów (1920×1080) |
| `landing.html`, `onepager.html`, `pitchdeck.html` | Materiały do PDF / strona demo |
| `OPISY_DLA_WNIOSKU.md` | Teksty pod formularz SPARK |
| `spark_recording_env.example.json` | Parametry demo (tenant, loginy — bez tokenów) |

## PDF z HTML (lokalnie)

1. Otwórz `onepager.html` lub `pitchdeck.html` w **Chrome**.
2. `Ctrl+P` → **Zapisz jako PDF** → marginesy: brak / minimalne, tło: włączone.

## Ponowne nagranie na własnym serwerze
