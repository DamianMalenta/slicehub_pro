# B-002 — Capability Registry i katalog Host Context

Zakres zatwierdzony przez właściciela 2026-09-14. Konstytucja 1.0.0. Status i dowody: [CURRENT_STATE](../CURRENT_STATE.md). Scenariusz oczekuje na ręczny odbiór właściciela.

## Aktor i cel

Administrator integracji B ogląda rzeczywisty, wersjonowany katalog kompetencji integracyjnych. Service A może pobrać tę samą listę przez osobny credential. Odkrycie nie nadaje prawa wykonania i nie jest sesją pracownika.

## UI

[Panel katalogu](../../modules/symbiont/capabilities.html) przyjmuje osobny klucz administratora B-002, pobiera listę z PHP i pokazuje host, środowisko, czas obserwacji, identyfikator, wersję, rodzaj, status, wymaganą rolę oraz brak skutków biznesowych. „Wyczyść i zablokuj” usuwa wynik, nie zmienia konfiguracji procesu. Brak konfiguracji lub błędny klucz nie uruchamia demo.

## Backend i kontrakt

Przypięty [capability-catalog v1](../../core/Symbiont/contracts/capability-catalog-v1.json) dopuszcza wyłącznie `catalog.list`. `CapabilityRegistry.php` waliduje lokalny deklaratywny katalog przed obsługą żądania. Endpointy `capabilities.php` i `capabilities-admin.php` mają oddzielne, niewymienne tokeny. DTO jawnie zwraca `execution=not_permitted`; wszystkie pozycje mają `business_effects=none`.

Katalog obejmuje wyłącznie istniejące operacje integracyjne: diagnostykę Bridge v1, odczyt zatwierdzonego snapshotu B-001 i samo listowanie katalogu. Nie publikuje kompetencji biznesowych ani nie przyjmuje tenant_id, SQL, ścieżki, URL lub parametrów wykonania.

## Stany błędne i niezmienniki

`DISABLED`, `UNAUTHORIZED`, `INVALID_REQUEST`, `UNSUPPORTED_VERSION`, `UNSUPPORTED_OPERATION`, `EMPTY_CATALOG`, `INTERNAL_ERROR`. Exact version, limit wejścia, brak redirectów po stronie klienta, TLS poza loopbackiem, tokeny poza DTO. Brak include `db_config.php`, sterowników DB w pilocie i tras ERP. Lista nie jest dowodem wdrożenia ani autoryzacją odkrytej pozycji.

## Testy i odbiór

`php tests/symbiont_capability_test.php`: kontrakt, kanały auth, disabled, TLS, limity, exact version, odmowa `capability.execute`, odmowa tenant_id i brak skutków. `node scripts/test-b002-http.mjs --host-root "C:/xampp/htdocs/slicehub"` w A: przypięcie kontraktu, prawdziwy izolowany PHP HTTP, panel DOM, osobne auth, odmowa wykonania oraz blokada tras DB/ERP. Lint PHP/JS i regresje A/B pozostają wymagane.

Ręcznie: uruchom izolowany pilot według [RUNBOOK_A](../RUNBOOK_A.md), otwórz panel B-002, pobierz listę właściwym kluczem, sprawdź odmowę innym kluczem, czytelność i wyczyszczenie. Odbiór wymaga jawnego potwierdzenia właściciela; agent nie wpisuje `ACCEPTED_BY_USER`.

## Non-goals

Brak wykonania kompetencji, sesji pracownika, danych MariaDB, domeny zamówień, STT/TTS, PTT, wake word, telefonii, urządzeń, migracji i produkcyjnego provisioningu.
